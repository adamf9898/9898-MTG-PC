# Goal

The single repo-wide goal of this project is to create an action, adventure, chaotic, multi-massive, open-world, custom magic the gathering, role-playing, web game with phaser, three.js, node.js, react, HTML, CSS, JavaScript, TypeScript, JSON, Markdown, Scryfall API fetching, Perchance generators, and AI interactivities.

## Progress Update (2026+)

- **Three.js integration:** See `src/scenes/scene-three-demo.html` for a working 3D demo.
- **React integration:** See `src/scenes/scene-react-demo.html` for a working React component demo.

These scenes confirm that Three.js and React are now present in the project and serve as templates for deeper integration into the open-world RPG gameplay.

- **Godot 4 prototype:** See `godot/` for a Godot 4.x prototype that runs alongside the web runtime. It mirrors GameState, CombatSystem, QuestSystem, EncounterGenerator, and CardSystem in GDScript, shares JSON data with `src/lib/`, and bridges to the Node.js backend via HttpBridge. Open `godot/project.godot` in Godot 4.3+.
