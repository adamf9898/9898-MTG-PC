Basic Iframe Embed

Use this when you want to embed a hosted Perchance generator page inside your site with no JavaScript required.

HTML — iframe
<!-- Basic Perchance embed -->
<iframe
  src="https://perchance.org/YOUR-GENERATOR-NAME"
  title="9898-MTG Chaos Pack Generator"
  width="100%"
  height="480"
  style="border:none;border-radius:8px;background:#0a0a0a;"
  loading="lazy"
  sandbox="allow-scripts allow-same-origin"
  aria-label="MTG Chaos Pack Generator">
  <p>Your browser does not support iframes.
     <a href="https://perchance.org/YOUR-GENERATOR-NAME">Open generator</a>
  </p>
</iframe>
Replace YOUR-GENERATOR-NAME with your Perchance slug. The sandbox attribute restricts the embedded page to scripts and same-origin requests only — safe for public embeds. loading="lazy" defers the iframe until it is in the viewport, improving page load time.

Styled Card-Display Wrapper

HTML + CSS
<!-- Wrapper with MTG-themed chrome -->
<style>
  .mtg-embed-wrapper {
    background: #0a0a0a;
    border: 2px solid #cc0000;
    border-radius: 12px;
    overflow: hidden;
    max-width: 640px;
    box-shadow: 0 0 32px #cc000044;
  }
  .mtg-embed-header {
    background: #1a0000;
    padding: 0.75rem 1.2rem;
    font-family: monospace;
    color: #cc0000;
    font-size: 0.9rem;
    letter-spacing: 1px;
    border-bottom: 1px solid #2a0000;
  }
  .mtg-embed-wrapper iframe {
    display: block;
    width: 100%;
    height: 480px;
    border: none;
  }
</style>

<div class="mtg-embed-wrapper">
  <div class="mtg-embed-header">⚔ 9898-MTG Chaos Pack Generator</div>
  <iframe
    src="https://perchance.org/YOUR-GENERATOR-NAME"
    title="MTG Chaos Pack Generator"
    loading="lazy"
    sandbox="allow-scripts allow-same-origin">
  </iframe>
</div>
Adds an MTG-styled header bar above the iframe. The box-shadow glow uses the brand red (#cc0000). Adjust max-width to fit your layout.

Responsive Embed with Aspect Ratio

HTML + CSS (responsive)
<style>
  .embed-ratio-box {
    position: relative;
    width: 100%;
    padding-top: 62.5%; /* 16:10 */
    background: #0a0a0a;
    border: 1px solid #2a0000;
    border-radius: 8px;
    overflow: hidden;
  }
  .embed-ratio-box iframe {
    position: absolute;
    inset: 0;
    width: 100%;
    height: 100%;
    border: none;
  }
</style>

<div class="embed-ratio-box">
  <iframe
    src="https://perchance.org/YOUR-GENERATOR-NAME"
    title="MTG Chaos Pack Generator"
    loading="lazy"
    sandbox="allow-scripts allow-same-origin">
  </iframe>
</div>
A CSS padding-top trick creates a responsive aspect-ratio container. Change 62.5% (16:10) to 56.25% for 16:9. The iframe stretches to fill the box at any viewport size.
