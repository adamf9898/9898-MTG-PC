Detailed Annotations

L14–15API Configuration

local SCRY_BASE = "https://api.scryfall.com"
local BACK_URL  = "https://i.imgur.com/yHEAQ88.jpeg"

SCRY_BASE: The only place the Scryfall domain appears. Changing this to a CORS proxy or local mock server redirects all traffic. Must not have a trailing slash.

BACK_URL: A static Imgur-hosted card back. Scryfall does not serve card backs. If Imgur removes the image, replace with any 745×1040-px JPEG URL.

L18–19Rate Limiting

local MIN_DELAY = 0.35
local MAX_RETRY = 3

MIN_DELAY: Scryfall asks for at most ~10 req/sec. 0.35 s ≈ 2.9 req/sec — conservative enough to avoid 429s while keeping spawn time reasonable for 15 cards (~5 s total).

MAX_RETRY: On HTTP errors or empty responses the script retries up to 3 times with exponential backoff before skipping the card slot.

L22Pack Size Cap

local MAX_PACK_SIZE = 30

Guards against accidentally spawning enormous stacks that can crash TTS. Default pack size is 15 (a standard booster); this cap allows up to 30 for double-booster variants but blocks anything larger.

L25–30Spawn Safety Guards

local COOLDOWN_SECONDS       = 15
local SPAWN_TIMEOUT_SECONDS  = 90
local _cooldownUntil         = 0
local _isSpawning            = false
local _spawnEndsAt           = 0

COOLDOWN_SECONDS: After a pack finishes spawning, the button is locked for 15 s. Prevents players from double-clicking and flooding the API.

SPAWN_TIMEOUT_SECONDS: If a spawn takes longer than 90 s (e.g., network stall), _isSpawning is force-reset so the script is not permanently locked.

_cooldownUntil / _isSpawning / _spawnEndsAt: Runtime state — never set these at file level after initialisation; they are managed exclusively by the spawn and cooldown logic.

L33–39Spawn Layout

local BTN_Y       = 0.35
local STACK_POS   = { x = 0, z = -5 }
local BASE_LIFT   = 7.0
local CARD_LIFT   = 0.20
local _stackIndex     = 0
local _deckIdCounter  = 1
local _nextTime       = 0

STACK_POS: World-space XZ for the card stack. z = -5 places it slightly in front of the button object on most TTS table layouts.

BASE_LIFT / CARD_LIFT: Card i spawns at y = BASE_LIFT + i * CARD_LIFT. The high BASE_LIFT means cards fall onto the table naturally and stack in order.

_stackIndex / _deckIdCounter: Incremented with each spawned card. Reset to 0/1 at the start of each pack to keep stacks clean.
