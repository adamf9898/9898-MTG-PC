Overview

The generator runs as a Lua script inside Tabletop Simulator (TTS). It uses the TTS built-in HTTP client and does not require external Lua packages — all dependencies are part of the TTS scripting environment. This section documents every API surface the script depends on.

TTS Built-in APIs

L14SCRY_BASE — Scryfall API Base URL

local SCRY_BASE = "https://api.scryfall.com"

Root URL for all Scryfall REST endpoints. The script appends paths such as /cards/random or /cards/search?q=... to this base. Changing this value to a proxy is the only change needed to redirect all API traffic.

Scryfall requires a descriptive User-Agent header. See Global Vars for the scryHeaders() helper.

L47WebRequest — TTS HTTP Client

WebRequest.get(url, headers, callback)
WebRequest.custom(url, method, headers, body, callback)

The Tabletop Simulator built-in HTTP client. It is available globally in the TTS Lua sandbox. The script uses WebRequest.get() for all Scryfall calls. Callbacks receive a request object with .text, .responseCode, and .error.

Not a standard Lua library — only available inside Tabletop Simulator scripts.

Built-inJSON.decode() — TTS JSON Parser

local data = JSON.decode(request.text)

Another TTS global. Parses the JSON string returned by Scryfall into a Lua table. Used immediately after a successful WebRequest callback to access card fields like data.name, data.image_uris.normal, and data.cmc.

Built-inspawnObject() — TTS Object Spawner

spawnObject({
  type   = "CardCustom",
  position = pos,
  rotation = {x=0,y=180,z=0},
  scale  = {x=1,y=1,z=1},
  callback_function = function(obj) ... end,
  sound  = false,
  parameters = { ... }
})

Core TTS API for creating objects on the table. The script spawns each card as a CardCustom with the Scryfall image URL assigned as the face texture and the back URL for the card reverse. The callback_function is used to set the card Nickname after spawn.

Built-inWait.time() — TTS Coroutine Timer

Wait.time(function() spawnNextCard() end, delay)

Used to implement the MIN_DELAY throttle between Scryfall API calls. Prevents rate-limit 429 responses by spacing requests 350 ms apart.

Built-inself:createButton() — TTS UI Button

self:createButton({
  label="Spawn Pack", click_function="onSpawnClick",
  function_owner=self, position={0,BTN_Y,0},
  rotation={0,0,0}, scale={1,1,1},
  width=1600, height=300, font_size=160
})

Registers a 3D button on the object that hosts the script. Clicking it calls onSpawnClick(), the main entry point for pack generation. BTN_Y controls the vertical offset above the surface.
