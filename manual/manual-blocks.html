Execution Flow

1
onLoad() — TTS calls this when the script loads. Registers the spawn button on the host object.
2
Player clicks button → onSpawnClick() fires.
3
Guards checked (cooldown, spawn lock, timeout). If clear → spawnPack(15).
4
For each card slot: fetchCard() → WebRequest.get() → onCardFetched().
5
onCardFetched() parses JSON, calls spawnCard().
6
After all cards: cooldown set, _isSpawning = false.

L45–50scryHeaders() pure

local function scryHeaders()
  return {
    ["User-Agent"] = "TTS-ChaosCommanderSpawner/1.0 (Tabletop Simulator)",
    ["Accept"]     = "application/json;q=0.9,*/*;q=0.8",
  }
end

Returns a fresh header table for every request. Scryfall's API policy requires a descriptive User-Agent; using a generic agent risks IP throttling. The Accept header signals JSON preference.

Always call this function rather than inlining headers — if Scryfall updates its policy, this is the only place to change.

L65+onSpawnClick(obj, playerColor) TTS event

function onSpawnClick(obj, playerColor)
  local now = os.time()
  -- Timeout safety: unlock if a previous spawn got stuck
  if _isSpawning and now > _spawnEndsAt then
    _isSpawning = false
  end
  if _isSpawning then
    broadcastToAll("Pack already spawning...", {1,0.5,0})
    return
  end
  if now < _cooldownUntil then
    broadcastToAll("Cooldown: " .. (_cooldownUntil - now) .. "s", {1,0.5,0})
    return
  end
  spawnPack(15)
end

Entry point called by the button. Implements three guards in order:

  1. Stuck-spawn timeout — releases the lock if the previous spawn exceeded SPAWN_TIMEOUT_SECONDS.
  2. Spawn lock — blocks concurrent spawns.
  3. Cooldown — enforces COOLDOWN_SECONDS between packs.

L85+spawnPack(size)

local function spawnPack(size)
  size = math.min(size, MAX_PACK_SIZE)
  _isSpawning   = true
  _spawnEndsAt  = os.time() + SPAWN_TIMEOUT_SECONDS
  _stackIndex   = 0
  _deckIdCounter = 1
  _nextTime     = 0
  for i = 1, size do
    Wait.time(function() fetchCard() end, (i-1) * MIN_DELAY)
  end
  Wait.time(function()
    _isSpawning  = false
    _cooldownUntil = os.time() + COOLDOWN_SECONDS
  end, size * MIN_DELAY + 2)
end

Orchestrates the pack spawn. Uses Wait.time() to stagger API calls by MIN_DELAY seconds. The final Wait.time() runs after all cards should have been requested and resets state.

The size * MIN_DELAY + 2 formula adds 2 s of headroom for slow responses. Increase to 5 on high-latency connections.

L105+fetchCard(retryCount)

local function fetchCard(retryCount)
  retryCount = retryCount or 0
  local url = SCRY_BASE .. "/cards/random"
  WebRequest.get(url, scryHeaders(), function(req)
    if req.is_error or req.response_code == 429 then
      if retryCount < MAX_RETRY then
        local backoff = 0.5 * (2 ^ retryCount)
        Wait.time(function() fetchCard(retryCount + 1) end, backoff)
      end
      return
    end
    onCardFetched(req.text)
  end)
end

Fetches a single random card from Scryfall. On HTTP error or 429 it retries with exponential backoff (0.5 s, 1 s, 2 s). After MAX_RETRY failures the slot is silently skipped.

L125+onCardFetched(jsonText)

local function onCardFetched(jsonText)
  local data = JSON.decode(jsonText)
  if not data or not data.image_uris then return end
  local imageUrl = data.image_uris.normal or data.image_uris.small
  local nickname = data.name
    .. " [" .. (data.cmc or "?") .. " CMC]"
    .. " — " .. (data.type_line or "")
  spawnCard(imageUrl, nickname)
end

Parses the Scryfall JSON response. Prefers normal image quality; falls back to small. Skips cards with no image_uris (tokens, etc.). Builds a Nickname string containing name, CMC, and type line.

L140+spawnCard(imageUrl, nickname)

local function spawnCard(imageUrl, nickname)
  local pos = {
    x = STACK_POS.x,
    y = BASE_LIFT + _stackIndex * CARD_LIFT,
    z = STACK_POS.z
  }
  _stackIndex = _stackIndex + 1
  spawnObject({
    type     = "CardCustom",
    position = pos,
    rotation = {x=0, y=180, z=0},
    scale    = {x=1, y=1, z=1},
    sound    = false,
    callback_function = function(obj)
      obj.setName(nickname)
    end,
    parameters = {
      face = imageUrl,
      back = BACK_URL,
    }
  })
  _deckIdCounter = _deckIdCounter + 1
end

Spawns a single CardCustom object at the calculated stack position. Cards are placed face-down (y=180 rotation) and stacked via incrementing _stackIndex. The callback_function sets the Nickname (visible on hover) after the card object initialises.
